# Jnthu-cgpa-sgpa-calculator-
A privacy-friendly JNTUH SGPA/CGPA calculator and semester tracker built with vanilla JavaScript. Data stays in your browser.  README intro  JNTUH SGPA &amp; CGPA Tracker is a web app that helps JNTUH students calculate their SGPA and CGPA and track academic progress across semesters. Add subjects with their credits and grades, and the app instantly computes each semester’s SGPA, your overall CGPA, an approximate percentage, and a bar chart of your performance over time.

Features

Credit-weighted SGPA and CGPA calculation
Multiple semesters with add/remove controls
Approximate percentage conversion
SGPA-per-semester chart
Data saved in the browser with localStorage, with no account and no server
Responsive layout with automatic dark mode

Tech: HTML, CSS, JavaScript (no frameworks or dependencies)

What I learned: separating calculation logic from UI code, DOM manipulation and event delegation, handling edge cases like empty input and divide-by-zero, persisting data with localStorage, and escaping user input to prevent XSS.
